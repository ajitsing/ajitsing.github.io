SAML response debugging guide

Capture a SAMLResponse during SSO

Use browser DevTools on the ACS POST: copy the SAMLResponse hidden field. For redirect binding, copy the query parameter from the location bar before the page navigates away.

Validate timing and audience

Check NotBefore and NotOnOrAfter against your server clock. Confirm Audience matches your SP entity ID. Skew or wrong audience is a frequent cause of silent login failures.

Certificates and signatures

When an X509Certificate is present, compare the SHA-256 fingerprint with the cert registered in your SP. For full PEM inspection, use the SSL/TLS Certificate Decoder.

SAML Response Decoder FAQ

How do I decode a SAMLResponse?

Paste the SAMLResponse form field, redirect parameter, or XML. The tool decodes Base64 and DEFLATE when needed.

How do I read SAML attributes?

Look at the AttributeStatement table for each attribute name and value returned by the IdP.

Is my SAML response uploaded?

No. Parsing stays in your browser with JavaScript only.

How do I decode SAMLRequest?

Use the SAML Request Decoder for AuthnRequest payloads before login.
